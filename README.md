# personal-hub

Cozy, smart personal website for NikPeg: links to Telegram/VK, pet project landings, life dashboard, experiments, and ideas — hosted self-managed with smooth animations and one warm visual style.

## Prototype

Static site, no build step:

- `index.html`
- `styles.css`
- `script.js`

Features:

- dark/light theme toggle
- EN/RU language toggle
- smooth reveal animations
- channel links
- placeholder landings for pet projects
- ready for self-hosting with `sslip.io`

## Local preview

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
