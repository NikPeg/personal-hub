# The Fragility of Comfort Zones

The world is changeable.

There used to be Snezhkom — it was so great there. And now what? Just videos of its demolition.

There used to be the Erti restaurant — we went there every day. Now it is some place called Select.

You need to create your own world, as independent from other people as possible, so that no one can destroy it.

If you have found a comfort zone, enjoy it fully.
