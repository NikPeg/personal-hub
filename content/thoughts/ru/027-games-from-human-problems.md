# Игры из задач человечества

Вообще эту идею можно развить дальше. Людям интересно всё, что решает нечёткая логика. Игра на решение задач — плохая идея. Можно просто взять задачи человечества, которые решают нейросети, и сделать по ним компьютерные игры.
