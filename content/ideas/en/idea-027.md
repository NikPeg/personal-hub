# Dishwasher for one plate!

Dishwasher for one plate!
A dishwasher is a huge and heavy device. It needs to be loaded, unloaded, and started: all this is hard and time-consuming, it’s easier to wash it. The solution would be a miniature version - for 1/2 plates. I installed it and it was clean in a minute. The size is like a multicooker. But it is not clear how to supply water to it. Should I pour MB into a special tank before each wash?
