# Book for programmers

Book for programmers
All professions have books about this profession. For example, criminologists have a lot of stuff about how someone investigates crimes. Such books are both interesting to these professions and educational for them. You can try something like this with programming. Show it not just like “uhhh, how can I code this, I don’t know”, but in detail, reveal the topic, show the mistakes of the organization, etc. MB even provide the code!
The same goes for cybersecurity, there could be a lot of interesting things
