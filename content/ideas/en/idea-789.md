# Personalizing Edya

Right now Edya is a single bot for everyone. It would be more interesting to let each chat create its own bot: users pick the avatar, personality, and so on.

This could become a real subscription service. A chat admin is motivated to keep members engaged, and a custom bot is a tool for that.
