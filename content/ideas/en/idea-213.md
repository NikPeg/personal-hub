# Self-developing neural network

Self-developing neural network
Perhaps, with the help of Sh., Kurisu and Lucy, we can study the process of the birth of neurons in the brain. There is an assumption that if there is too much load on one neuron (many signals per second), it bifurcates into 2. There is no problem doing this programmatically, but I have no knowledge of how this happens in nature.
The first goal of the experiment is probably to achieve learning ability of some animal. Firstly, fruit flies - for example, looking for fruit somewhere, and ideally mice in a maze, as in Flowers for Algernon. You can emulate the same thing in a computer, like a neural network controls the flight of a fly
