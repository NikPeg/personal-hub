# New program for artists using neural networks

New program for artists using neural networks
Even a type of Photoshop with the command line. Neural networks gradually adapt to the artist’s style. Ideally, the drawing can be drawn in a few seconds.
-Draw a person
The neural network adds a human layer in the user's style.
-Make your face angrier
The neural network changes the facial expressions of the hero
-T-shirt color is brighter
And so on. Most of the artist’s work can already be done by neural networks. You just need to leave creativity.
It is necessary to make sure that the user himself sets new commands
Maybe something like 3D models. The man says: draw a bench. The neural network loads a 3D model of a bench and displays it in an artist's style. The artist can arrange it the way he needs
