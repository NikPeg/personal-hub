# I came up with an idea about a wardrobe without numbers.

I came up with an idea about a wardrobe without numbers.
Option one: the security guard has in her hands something like a thing for checking tickets on the bus. The user taps the phone/pass (synchronized), the NFC sensor remembers, and a number is displayed on the screen, to which the clothes are hung.
