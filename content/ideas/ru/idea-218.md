# Расширение "подборки вкладок" для хром

Расширение "подборки вкладок" для хром
Тип, вкладка учеба — график, решуегэ, кюизлет
вкладка работа — еще че-нить
вкладка отдых — комиксы, ютуб, вк
Чтоб каждый раз по десять вкладок не открывать
Не знаю, реализуется это или нет
