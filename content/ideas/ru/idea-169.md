# Приложение для выгодных покупок

Приложение для выгодных покупок
Приложение/сайт/бот
Пользователь выбирает магазины, в которых хочет закупаться (те, что рядом с домом)
И вводит список продуктов, которые ему нужны (типа мясо, рыба)
Когда юзер приходит в магазин, приложение показывает ему список покупок — то, что самое дешевое именно в этом магазине
Нужно учесть срок годности продуктов — продукт со сроком годности месяц нужно брать по самой выгодной цене за месяц
Нужно добавить фичу — пользователь может убрать продукт данного типа (что-то слишком дешевое, например), если он ему не понравился, и он больше не будет попадаться в списке покупок
