# Индустрия развлечений для котов

Индустрия развлечений для котов
1) планшеты с нецарапываемым экраном, чтобы показывать котам игры и видео
2) аттракцион. Отслеживает поведение кота, его реакцию на происходящее на экране. В соответствии с этим меняет картинку. Например, мышь убегает. С помощью камер/дальномеров/инфравизоров
3) развитие интеллектуальных способностей котов. Обучающие игры. Разобраться, почему коты не воспринимают других котов на видео. Если поймём, можно показывать сериалы/фильмы
4) использовать еду в качестве стимула для кота. Тип за хорошие результаты – еда
