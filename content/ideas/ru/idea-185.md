# Приложение для обучения, в основе которого бинпоиск. Есть пак задач (большой!). Челове

Приложение для обучения, в основе которого бинпоиск. Есть пак задач (большой!). Человеку дается серединная задача. Решает - ему дается серединная задача из верхней половины, не решает - из нижней. Так приложение определяет уровень человека в этой теме и постепенно его поднимает
