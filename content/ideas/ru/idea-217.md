# Применение нейросети, которая может логически мыслить

Применение нейросети, которая может логически мыслить
Во-первых, тогда возможно проверять решения по математике
Во-вторых, можно сделать игру
Тип уровни – теоремы. В начале у игрока открыты только аксиомы, чувак пишет решение, открывает следующую теорему, на нее теперь можно ссылаться. Так можно игрофицировать всю геометрию
