# Идеальный язык

Идеальный язык
Взять ту азбуку всех звуков человечества (где-то видел статью на Википедии – собраны все звуки из всех языков), взять слова по частоте употребления, задать им наборы звуков по длине (исключая труднопроизносимые). Создать язык, в котором информацию можно передать короче всего

Наиболее экономная запись числа – по основанию. Мб с языком надо делать то же? Например:
Каждое предложение несёт информацию по следующим параметрам:
Кто? Что сделал? Когда? Как?..
Мб каждое слово – "бит" информации? Это говорит, например, о том, что можно одно и то же слово использовать для глагола и для существительного
