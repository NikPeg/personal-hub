# Набор для приготовления еды для домашних животных. Ведь на самом деле в их еде нет нич

Набор для приготовления еды для домашних животных. Ведь на самом деле в их еде нет ничего необычного, и непонятно, зачем ВСЕ кормят их покупной едой, хотя себе готовят сами. Можно было бы сделать постепенное преобразование общества:
1) дорогой набор для приготовления еды для кошек (инстаграм-магазин)
2) Когда он достигнет пика популярности, создать портал, где выкладывать разнообразные рецепты для котов. На нем же можно заказать поставку редких ингридиентов (которые сложно найти в магазине)
3) Когда и этот способ заработка достигнет максимума, начать заключать контракты с зоомагазинами о поставке тех редких ингридиентов (мб с рецептами на упаковке)
4) Предел - контракты с продуктовыми магазинами о поставке ингридиентов
(5) Самому создать завод по производству этих компонент для еды животных
Вероятные проблемы:
1) люди не захотят готовить в своей посуде еду для животных (лол конечно, то же мясо). Тем лучше - можно продать специальную "кастрюлю" для кошачьей еды
2) животным нужно готовить очень мало, возможно, некоторые будут думать, что проще купить пачку, чем так много готовить. Для решения этой проблемы нужно указывать повсюду, что полученную еду можно хранить как покупную
