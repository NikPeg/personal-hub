# Сайт вроде знания.ру, где можно публиковать только видео. То есть каждая тема/задача о

Сайт вроде знания.ру, где можно публиковать только видео. То есть каждая тема/задача объясняется в видео. Потом будет нечто вроде стэковерфлоу для всех предметов
Будет популярным, потому что это отличная возможность прорекламироваться всяким репетиторам и онлайн-каналам. Будут соревноваться кто круче, ученики на них натыкаются, подписываются/приходят учиться
Стратегию монетизации в принципе можно срисовать с знания.ру — сначала быть бесплатными, очень раскрутиться, стать лидирующим продуктом в своей области, потом зделать чет тип платной подписки, чтобы получить доступ к урезанным функциям
Второй вариант — донательный. Если 3 стадия ц.э. наступит, прикрутить возможность донатить и пошло поехало
