# Звонки на английском

Звонки на английском
Для удобного общения на английском
Представь, идешь домой, открываешь приложение
Звонок, находится случайный собеседник, общаешься
Потом гудки, находится новый собеседник
Можно добавлять друзей, смотреть, кто из них онлайн, звонить им потом

По-моему, была такая идея прост для общения, теперь вот для обучения еще

Есть еще идея добавить темы для разговора, чтоб тип знали, о чем говорить
