# Приложение для автоматической проверки самостоятельных

Приложение для автоматической проверки самостоятельных
Зафигачить туда систему чтения с изображения
Тогда тип ученики пишут тест на листочке, сдают
Учительнице достаточно просто пофоткать все, автоматически создается статистика
В идеале, чтоб сразу загружалось в элжур
