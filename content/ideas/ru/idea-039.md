# Формализация философии. Сделать развитый портал о философии (возможно, курируемый каки

Формализация философии. Сделать развитый портал о философии (возможно, курируемый каким-нибудь институтом), где были бы собраны строгие ответы на все философские вопросы. Наиболее общий подход. То есть
Наука физика, например, строилась так: высказывается теория, находится эксперимент, ее опровергающий, высказывается новая теория.
Математика так: высказывается теория, в ней находится ошибка, высказывается новая теория
То же можно сделать с философией. Например, Платон сказал то-то, на это через 500 лет Декарт возразил то-то. Так, человек, прочитав развитие философии по каждому вопросу, сможет найти ответ на любой вопрос
Здесь стоит учесть следующее: Не у всех людей одинаковые аксиомы, то есть отношение к разным вещам. То есть человек, для которого любовь важнее долга, может прийти к противоположным взглядам, чем тот, у кого наоборот. Поэтому
1) Перед входом на сайт дать человеку расставить приоритеты для каждого из основных чувств (или что есть более основное?)
2) Когда человек переходит от одного высказывания философа к другому, сделать ему "разветвление", условный оператор - что для вас важнее?

На самом деле эта идея очень важна. Человек может ошибаться много лет, не понимая простых вещей. Прочитав нужную книгу, он мог бы прожить свою жизнь совсем иначе! Цель этого сайта - собрать достижения всего человечества по каждому вопросу человеческого знания.
