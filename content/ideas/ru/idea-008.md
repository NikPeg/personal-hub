# Сайт, в котором будет отражена статистика мнения пользователей по каждому товару. На п

Сайт, в котором будет отражена статистика мнения пользователей по каждому товару. На примере телефонов:
Каждый юзер проходит тест, оценивает качество каждого параметра. Зайдя на страницу телефона, можно узнать мнение людей
Самое важное: срок службы. Зная, сколько времени будет служить телефон, можно оценивать его реальную стоимость
