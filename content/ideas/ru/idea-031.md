# Новая программа для художников с использованием нейронных сетей

Новая программа для художников с использованием нейронных сетей
Чет тип фотошопа с командной строкой. Нейросети постепенно подстраиваются под стиль художника. В идеале рисунок может быть нарисован за несколько секунд.
-Нарисуй человека
Нейросеть добавляет слой человека в стиле пользователя.
-Сделай лицо позлее
Нейросеть изменяет мимику на лице героя
-Цвет майки поярче
И так далее. БОльшую часть работы художника уже могут сделать нейронные сети. Нужно оставить только творчество.
Нужно сделать, чтобы пользователь сам задавал новые команды
Можно что-нибудь вроде 3-д моделей. Человек говорит: нарисуй скамейку. Нейронная сеть загружает 3-д модель скамейки и показывает ее в стиле художника. Художник может расположить ее так, как ему нужно
