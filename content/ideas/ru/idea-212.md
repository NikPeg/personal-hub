# Бот для тг для контура вокруг стикеров

Бот для тг для контура вокруг стикеров
Отправляешь ему файл с прозрачным фоном со стикером, он автоматически делает обводочку (прост вдоль контура с округлыми краями)
Можно отдельно настроить толщену контура
В идеале чтоб он сразу добавлял стикер в набор, но, как помнишь, боты в тг общаться не могут
